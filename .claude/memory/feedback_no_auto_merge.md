Never merge PRs automatically. Only create the PR and wait for user to say "merge".

**Why:** User asked to "create merge request" and I merged it without approval. User was upset.

**How to apply:** When user says "create PR" / "create merge request" — only create it. Stop there. Wait for explicit "merge it" / "merge the PR" before merging.
